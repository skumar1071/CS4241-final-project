# Project Proposal

**Members:** Vu Nguyen, Wen Chen, Shubham Kumar

## Description

An interactive, web-based game inspired by *Dungeons & Dragons*. The application will allow players to create and manage custom characters, including their health, items, abilities, and money to go through an interactive choice-based campaign. Dungeon Masters (DMs) will be able to create encounters, shops, enemies, items, and loot for their campaigns.

## Key Functionalities

* **User Authentication**

  * Register and create an account
  * Log in using OAuth

* **Character Creation**

  * Create custom player characters
  * Manage character health, items, abilities, class, and level

* **3D Dice Roller**

  * Roll virtual 3D dice
  * Use dice results for damage and other game actions

* **Encounter Builder**

  * Create encounters containing one or more enemies
  * Set enemy and player-character health
  * Use fixed or rolled damage values
  * Add custom flavor text
  * Save encounters for future use or planning

* **Campaign Management**

  * Create and save campaigns
  * Organize saved encounters within each campaign
  * Share campaigns and encounters with other users

* **Content Creation**

  * Provide boilerplate encounters, shops, items, and loot
  * Allow DMs to create custom enemies, shops, items, and loot

* **Money Management**

  * Track player currency
  * Create shops for campaign players
  * Allow players to purchase items

## Key Technologies and Libraries

* MongoDB
* Express.js
* React.js
* Node.js
